# 42 Days of ML Challenge 🚀

> **From zero to production-ready ML Engineer. In public. For free.**

Most ML content is either too theoretical to use or too shallow to matter. This challenge is different. Every day for 42 days, you get a concept, a real company example, a working notebook, a production-level problem engineers actually face, and an MNC interview question with answer direction. We keep consuming a lot and building less. So lets start learning by building.

I'm not teaching from a stage. I'm building this with you.

---

## What You Get Every Day

- **The concept** in plain English, no unnecessary jargon
- **How a real company uses it** with a specific, documented example
- **A working Colab notebook** you can run in your browser today
- **A real production problem** engineers face with this concept and how they fix it
- **An MNC interview question** with what they're testing and how to answer it
- **ML Spotlight** - a real tool, library, or paper tied to that day's concept

Every 7 days: a revision post with 5 MNC interview questions, practice projects, and a community challenge.

---

## Before You Start

**Read the [Prerequisites Guide] first.**

You need solid foundations in Python, Linear Algebra, Calculus, and Statistics before Day 1. The prerequisites guide tells you exactly what to study, how long it takes, and has a self-check so you know when you're ready.

If you jump to Day 1 without the foundations, you'll copy code you don't understand. That's not the goal here.

## How to Use This Repo

**If you're starting from zero:**
Go to the [Prerequisites Guide](prerequisites/) first. Come back when you can pass the self-check.

**If you're following the LinkedIn series:**
Each day's post links directly to that day's folder. Open the notebook in Colab, run every cell, then attempt the practice exercise at the end before looking at the solution.

**If you're using this for interview prep:**
Every revision post folder contains the 5 MNC interview questions for that week with full answer direction. Start there, then go back to the daily notebooks for the concepts you feel shaky on.

**If you found this repo without the LinkedIn series:**
Start at Day 1 and work through in order. Each concept builds on the previous one. Skipping ahead will work until it won't.

---

## Running the Notebooks

Every notebook has an **Open in Colab** badge at the top. Click it. No installation needed. All dependencies are installed inside the notebook.

If you want to run locally:

```bash
git clone https://github.com/VaishnaviJagtap18/42-days-aiml-challenge.git
cd 42-days-aiml-challenge
pip install -r requirements.txt
jupyter notebook
```
